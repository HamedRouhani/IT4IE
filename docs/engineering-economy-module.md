## ۱. هدف و مرز ماژول

این ماژول تحلیل‌های **اقتصاد مهندسی** را برای انتخاب بین گزینه‌ها، توجیه سرمایه‌گذاری، جایگزینی دارایی و ارزیابی پروژه‌های عمومی انجام می‌دهد.

**در دامنه:**
- جریان نقدی چندساله، ارزش زمانی پول، معادل‌ها (PW/FW/AW)
- معیارهای پذیرش: NPV، IRR، ERR/MIRR، دورهٔ بازگشت ساده و تنزیل‌شده، شاخص سودآوری، نسبت فایده به هزینه (B/C) و تحلیل افزایشی
- استهلاک و مالیات (جریان نقدی پس از مالیات)
- تورم و تبدیل نرخ اسمی/حقیقی
- تحلیل جایگزینی و عمر اقتصادی دارایی
- تحلیل حساسیت یک‌متغیره، نقطهٔ سربه‌سر و ارزش تغییر (switching value)
- مستندسازی فرض‌ها و ثبت نسخهٔ تحلیل برای بازبینی

**خارج از دامنه (به ماژول‌های دیگر واگذار می‌شود):**
- تصمیم‌گیری چندمعیاره با مقایسات زوجی → ماژول MCDM
- پیش‌بینی آماری تقاضا → StatLab / Inventory
- مدل‌سازی ریسک شهودی و شبیه‌سازی گسترده → فاز بعد همین ماژول (اختیاری)

## ۵. کاتالوگ فرمول‌ها

نمادها: `i` نرخ دوره، `n` تعداد دوره، `A` مبلغ یکنواخت، `P` ارزش فعلی، `F` ارزش آتی، `G` گرادیان.

**فاکتورها**
- `(P/F,i,n) = (1+i)⁻ⁿ`
- `(F/P,i,n) = (1+i)ⁿ`
- `(P/A,i,n) = ((1+i)ⁿ − 1) / (i(1+i)ⁿ)` برای `i ≠ 0` و `= n` برای `i = 0`
- `(A/P,i,n) = i(1+i)ⁿ / ((1+i)ⁿ − 1)`
- `(F/A,i,n) = ((1+i)ⁿ − 1) / i`
- `(A/F,i,n) = i / ((1+i)ⁿ − 1)`
- گرادیان: `(P/G,i,n) = (1/i)[(P/A,i,n) − n(P/F,i,n)]`، `(A/G,i,n) = (1/i) − n/((1+i)ⁿ − 1)`
- گرادیان هندسی با رشد `g`، `g ≠ i`: `P = A₁[1 − ((1+g)/(1+i))ⁿ] / (i − g)`

**معیارهای تصمیم**
- `NPV = Σ CF_t (1+i)⁻ᵗ`
- `FW = NPV·(1+i)ⁿ` · `AW = NPV·(A/P,i,n)`
- `EUAC = P(A/P,i,n) − S(A/F,i,n) + A_costs`
- هزینهٔ سرمایه‌شده (عمر نامحدود): `CC = P + A/i`
- `IRR`: ریشهٔ `NPV(i) = 0`؛ اگر تغییر علامت جریان نقدی بیش از یک بار باشد، وجود چند ریشه بررسی و **هشدار** داده می‌شود (Descartes).
- `ERR`: نرخ `i*` که `Σ outflow·(F/P,i*,n−t) = Σ inflow·(F/P,MARR,n−t)`
- `MIRR = (FV(inflows @ reinvest) / −PV(outflows @ finance))^(1/n) − 1`
- `PB`: کوچک‌ترین `k` که `Σ_{t≤k} net_t ≥ 0` (با درون‌یابی)؛ `DPB` همان با جریان تنزیل‌شده
- `PI = PV(inflows) / |PV(outflows)|`
- `BCR = PW(benefits) / PW(costs)` و `SIR = PW(savings) / PW(investment)`؛ برای مقایسهٔ بیش از دو گزینه، **BCR افزایشی** ملاک است نه BCR مطلق.
- تحلیل افزایشی: `ΔIRR` روی تفاضل جریان‌های دو گزینه با ترتیب صعودی سرمایهٔ اولیه.

**مالیات و استهلاک**
- `ATCF_t = (R_t − C_t − D_t)(1−T) + D_t` (D فقط برای سپر مالیاتی؛ سرمایه‌گذاری در سال صفر بدون اثر مالیاتی)
- استهلاک مستقیم: `D = (P − S)/N`
- نزولی: `D_t = BV_{t−1}·d` با نرخ `d` و امکان تغییر به خط مستقیم
- مجموع سنوات: `D_t = (P − S)·(N − t + 1)/(N(N+1)/2)`
- واحد تولید: `D_t = (P − S)·(units_t / units_total)`

**تورم**
- `(1 + i_market) = (1 + i_real)(1 + f)`؛ تبدیل هر جریان به پول جاری/ثابت
- افزایش سالانهٔ هزینه‌ها با نرخ اختصاصی هر ردیف (اختیاری)

**جایگزینی و عمر اقتصادی**
- `EUAC(k)` برای `k = 1..N`؛ سالی که کمترین EUAC را دارد = عمر اقتصادی
- رویارویی مدافع/چالشگر: مقایسهٔ EUAC با افق مشترک یا تحلیل افزایشی

**عدم‌قطعیت**
- حساسیت یک‌متغیره: تغییر ±۱۰٪/±۲۰٪ هر پارامتر و ثبت شیب NPV
- ارزش تغییر: درصدی از پارامتر که `NPV = 0` می‌شود
- سناریو: MARR/تورم/مالیات متفاوت با نتیجهٔ جداگانه

**برآورد هزینه (کمکی)**
- قاعدهٔ شش‌دهم: `C₂ = C₁(Q₂/Q₁)^x` با `x` پیش‌فرض 0.6

## ۸. اعتبارسنجی و محافظ‌ها

- `i > −100%`؛ `n ≥ 1` و `n ≤ 100`؛ `MARR` بین ۰ و ۱۰۰٪.
- حداقل یک جریان منفی و یک جریان مثبت برای IRR.
- رد `n` غیرپیوسته یا سال تکراری.
- هشدار صریح: NPV و IRR فقط با فرض‌های ثبت‌شده معتبرند؛ IRR تک‌نرخی نیست.
- مجموع allowance معادل در این ماژول وجود ندارد؛ اما `MARR` باید مستند شود (WACC، نرخ فرصت، سیاست سازمان).
- گرد کردن فقط در نمایش؛ محاسبه با دقت کامل.

**بردارهای آزمون (برای tests/reference):**
- `(P/A,10%,5) = 3.790787` · `(A/P,10%,5) = 0.263797` · `(P/F,10%,5) = 0.620921`
- `NPV(−10000, +3000×5 @10%) = 1372.36`
- `IRR` همان جریان ≈ `15.24%`
- استهلاک مستقیم `(10000, 2000, 5)` = `1600/سال`؛ `SOYD` سال اول = `2666.67`؛ نزولی ۲۰٪ = `2000`
