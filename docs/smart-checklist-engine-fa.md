# موتور چک‌لیست هوشمند

موتور چک‌لیست از قواعد شاخه‌ای برای انتخاب پرسش بعدی استفاده می‌کند. پاسخ‌دهنده فقط پرسش‌هایی را می‌بیند که در مسیر پاسخ‌هایش قرار گرفته‌اند؛ امتیاز و نتیجه نیز فقط از همان پرسش‌ها محاسبه می‌شود.

## راه‌اندازی نسخه

پیش از انتشار کد، اسکریپت زیر را یک‌بار روی پایگاه‌دادهٔ سایت اجرا کنید:

`app/database/migrations/2026_11_18_checklist_branching.sql`

این اسکریپت ستون JSON اختیاری `branching_rules` را به جدول `checklist_questions` اضافه می‌کند. چک‌لیست‌های فعلی که این ستون برایشان خالی است، همچنان به ترتیب عادی اجرا می‌شوند.

## تنظیم مسیرها

از پنل مدیریت، وارد مدیریت پرسش‌های یک چک‌لیست و سپس ویرایش هر پرسش شوید. برای هر پاسخ یکی از این مقصدها را انتخاب کنید:

- **پرسش بعدی به ترتیب:** ادامهٔ مسیر معمول.
- **یک پرسش آینده:** پرش به پرسش فعال دیگری که پس از پرسش جاری قرار دارد.
- **پایان ارزیابی:** توقف مسیر و رفتن به نتیجه.

چهار پاسخ امتیازی عبارت‌اند از ۰ (خیر)، ۱ (به‌ندرت)، ۲ (تاحدودی) و ۳ (بله، به‌شدت). مقصد پرسش فقط رو به جلو انتخاب می‌شود تا حلقه در طراحی مسیر ایجاد نشود. اگر مقصدی حذف یا غیرفعال شود، مسیر به پرسش بعدی به ترتیب برمی‌گردد.

## ذخیره و امتیازدهی

قواعد هر پرسش به‌صورت JSON در همان رکورد پرسش نگهداری می‌شوند. مرورگر برای تجربهٔ مرحله‌ای مسیر را دنبال می‌کند و هنگام ثبت نهایی، سرور مسیر را دوباره از روی پاسخ‌ها محاسبه می‌کند. پاسخ‌های خارج از مسیر در نتیجه ذخیره یا امتیازدهی نمی‌شوند.
