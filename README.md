# 🏭 IT4IE (Information Technology for Industrial Engineering)

[![PHP Version](https://img.shields.io/badge/PHP-8.2+-blue.svg)](https://php.net)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Architecture](https://img.shields.io/badge/Architecture-Modular%20MVC-orange.svg)]()

پلتفرم جامع و ماژولار **IT4IE** یک سیستم تحت وب تخصصی برای مهندسین صنایع، مدیران پروژه و تحلیلگران کسب‌وکار است. این پلتفرم با معماری ماژولار (Modular MVC) طراحی شده و ابزارهای استانداردی مانند BABOK، PMBOK، QMS و MCDM را به صورت یکپارچه و هوشمند ارائه می‌دهد.

---

## ✨ ویژگی‌های کلیدی

- 🧩 **معماری ماژولار**: افزودن یا حذف نرم‌افزارها بدون تداخل در هسته اصلی سیستم.
- 🤖 **دستیار هوشمند (AI Assistant)**: پیشنهاد خودکار روش‌ها و معیارها بر اساس ویژگی‌های مسئله.
- 📊 **داشبوردهای تحلیلی**: گزارش‌گیری پیشرفته، نمودارها و تحلیل حساسیت.
- 🎨 **رابط کاربری واکنش‌گرا (Responsive)**: طراحی مدرن با Bootstrap 5، فونت وزیرمتن و تم‌های اختصاصی برای هر ماژول.
- 🔐 **مدیریت دسترسی و لاگ فعالیت‌ها**: ثبت دقیق تمام اقدامات کاربران (Activity Logs) برای ردیابی و حسابرسی.

---

## 📦 ماژول‌های نرم‌افزاری

### 1. 🧠 BABOK Analyzer (تحلیل کسب‌وکار)
- مدیریت چرخه حیات نیازمندی‌ها بر اساس استاندارد BABOK v3.
- استخراج هوشمند نیازمندی‌ها از متن (NLP).
- بانک جامع تکنیک‌ها و وظایف (Tasks) با نمونه‌های کاربردی.

### 2. 📅 PMBOK Analyzer (مدیریت پروژه)
- مدیریت فرآیندها و حوزه‌های دانشی بر اساس PMBOK.
- مدیریت ریسک، ذی‌نفعان و تحویل‌دادنی‌ها (Deliverables).
- ردیابی پیشرفت پروژه و فازبندی (Initiation to Closure).

### 3. ⚖️ MCDM Analyzer (تصمیم‌گیری چندمعیاره) - *جدید*
- پشتیبانی از روش‌های **AHP, TOPSIS, VIKOR, SAW, ELECTRE, PROMETHEE, BWM, ANP**.
- دستیار هوشمند برای پیشنهاد بهترین روش بر اساس نوع مسئله.
- محتوای آموزشی غنی (مبانی ریاضی، گام‌های اجرایی، ورودی/خروجی هر گام).
- قالب‌های آماده برای صنایع مختلف (تولیدی، نفت و گاز، IT، خدماتی).

## 🛠️ پشته فناوری (Tech Stack)

- **Backend**: PHP 8.2+ (Custom Modular MVC Framework)
- **Database**: MySQL / MariaDB (UTF8MB4)
- **Frontend**: HTML5, CSS3, Vanilla JavaScript, Bootstrap 5
- **Fonts**: Vazirmatn (فونت استاندارد فارسی)
- **Icons**: Font Awesome 6
